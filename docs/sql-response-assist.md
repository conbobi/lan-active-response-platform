# ADR — SQL injection response assist

Use the incident's HTTP evidence group and its same-Agent web_access_logs as the authority for proposals. Access-log metadata establishes observations and probing. A successful response code or an uncorrelated authentication event cannot establish application compromise. Persist proposals in response_actions, transitions in action_audit_logs and dispatch in commands. The authenticated network_refresh adapter already produces a command-bound network snapshot. Reuse its worker, deadline, no-retry policy, Agent credential and ACK verifier.

The first executable response collects time-bounded Manager records and requests an Agent snapshot. Operators with Agent scope can propose and review collection. Only configured administrators can dispatch it. Collection does not change traffic and has no rollback. Existing firewall transactions change UFW configuration, but the captured HTTP source lacks a verified relationship to the enforcement point. Keep traffic intervention unavailable until this relationship and a scoped expiring adapter are validated. Flask uses client-side signed sessions and the HTTP evidence does not identify a process. Incident resolution is a separate analyst decision.
